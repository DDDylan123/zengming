## 书写方式（v2.1）

字幕和片名不再整句淡入，而是一笔一画写出来：汉字按真实笔顺，字形为楷体。笔画数据取自 Make Me a Hanzi（graphics.txt，Arphic 公共许可），数据集缺的"珺"用"王""君"拼成，标点为手工定义。英文用 Caveat 手写字体（SIL 开放字体许可）从左往右显出。沙堡先用细线起稿，沙粒再填进去。

| 类别 | 写法 |
|---|---|
| 原话 | 深棕楷体，按笔顺写出，加「」 |
| 转述 | 蓝色楷体，按笔顺写出 |
| 补充 | 深棕细笔（单线），按笔顺写出 |
| 反方 | 粗笔（单线），反相画面里为米白色 |

字幕文字、类别和出处与下表相同，没有改动。

## 四类标签

| 标签 | 含义 | 画面上的样子 |
|---|---|---|
| **原话 · 曾鸣** | 节目页摘录的曾鸣原话，字词不改 | 橙色实心标签，宋体粗字，加「」 |
| **转述 · 曾鸣观点** | 曾鸣说过的观点，本片换了说法 | 深棕描边标签，宋体，不加「」 |
| **补充 · 本片** | 本片自己加的数据、例子、推断 | 虚线标签，黑体，不加「」 |
| **反方 · 本片观点，非曾鸣原意** | 本片反驳曾鸣的观点 | 整段画面反相成深棕底，四周加框，左上角常驻"反方 · 本片观点" |

原话来源、处理方式（只断行、中英文间加空格、截取标"节选"）和 Q 编号，与 `script/film-v1-字幕对照.md` 相同，原句全文见那份文件。

## 画面隐喻也算补充

整片的海滩、沙堡、海浪、小人都是本片的创作，不是曾鸣的说法。"巨浪"二字取自 Q12「我从来觉得在巨浪面前没有人是安全的」。

| 画面 | 依据 |
|---|---|
| 沙堡高度 | 按真实市值比例（数据见文末），AOL、YAHOO 被冲后的小沙丘高度按售价比例 |
| 把 AOL、YAHOO、GOOGLE、FACEBOOK 归入三个阶段 | 本片推断（曾鸣的三阶段原话讲的是 AI） |
| OpenAI、Anthropic 的沙堡与 AOL 同形 | 依据 Q4 把模型公司比作 AOL；高度为示意，不代表估值 |
| 一排一模一样的沙堡被浪压成一道堤 | 本片对 Q8"同质化的供给"和 Q6"公共基础设施"的图示 |
| 堤上的标签"公共基础设施""AI 云" | 措辞取自 Q6、Q5 |
| 需求连向多种能力的网 | 本片对 Q10 的示意 |
| 蓝色石头"智能"，碎成沙、再立起来 | 反方，本片观点 |
| 小人（取自 Dylan He 的 logo）与"我们在这里" | 本片对 Q3 的图示 |
| 结尾空海滩上的新光点 | 本片 |
